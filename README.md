## 1. الرؤية والأهداف (Project Vision)

هذا المشروع يهدف إلى بناء **منصة سحابية متعددة الاستخدامات وقائمة على الموديلات (Versatile & Modular Cloud Platform)**. الفكرة الجوهرية هي تمكين المؤسسات، بغض النظر عن قطاعها، من بناء نظام إدارة مخصص لاحتياجاتها الدقيقة عبر تفعيل أو تعطيل مجموعة من الموديلات الوظيفية المستقلة (مثل المحاسبة، إدارة العقارات، الفواتير، إلخ).

## 2. المبادئ الحاكمة للمشروع (Guiding Principles)

هذا المشروع يُبنى وفقًا لدستور واضح من المبادئ لضمان جودته واستدامته:

1.  **الموديل أولاً (Module-First):** نحن لا نبني ميزات، بل نبني "تطبيقات" مستقلة يمكن تركيبها على النواة الأساسية.
2.  **التهيئة بدلًا من البرمجة (Configuration over Code):** كل سلوك متغير يجب أن يكون قابلاً للإدارة من لوحة التحكم.
3.  **كل شيء قابل للربط (Everything is Linkable):** تصميم قاعدة البيانات يسمح بربط أي كيان بآخر، مما يوفر رؤية شاملة.
4.  **تجربة المستخدم المتسقة (Consistent UX):** هوية بصرية موحدة ومخططات صفحات قياسية (Blueprints) لضمان تجربة بديهية.
5.  **لا تكرر نفسك (DRY):** أي منطق مكرر يتم تحويله إلى مكون مركزي قابل لإعادة الاستخدام.
6.  **الأمان والموثوقية المدمجة (Security & Reliability by Design):** الحماية عبر الصلاحيات، الحذف الناعم، وسجل الحركات هي أجزاء أساسية وليست إضافية.

## 4. هيكلية المشروع (Folder Structure)

تم تصميم الهيكلية لتكون نظيفة وتدعم "فلسفة الموديلات":

```
/
├── app/                      # قلب التطبيق والمنطق البرمجي
│   ├── Common/               # النواة الإدارية المشتركة (مستخدمين، أدوار، إعدادات)
│   │   ├── Controllers/
│   │   └── Views/
│   ├── Modules/              # تطبيقات الأعمال المستقلة (سيتم بناؤها لاحقًا)
│   │   ├── RealEstate/
│   │   └── Invoicing/
│   ├── Config/               # ملفات الإعدادات (database.php, routes.php, firewall.php)
│   └── Helpers/              # الدوال المساعدة العامة (functions.php)
│
└── public/                   # المجلد العام الوحيد القابل للوصول
    ├── assets/               # ملفات CSS, JS, والموارد
    └── index.php             # نقطة الدخول الوحيدة للتطبيق (Front Controller)
```

## 6. كيفية إعداد المشروع محليًا (Setup Guide)

1.  **استنساخ المستودع:**
    ```bash
    git clone [URL_OF_YOUR_REPOSITORY]
    ```
2.  **إعداد قاعدة البيانات:**
    *   أنشئ قاعدة بيانات جديدة (e.g., `business_os_db`).
    *   قم باستيراد ملف `.sql` إذا كان موجودًا.
    *   عدّل بيانات الاتصال في `app/Config/database.php` (اسم القاعدة، المستخدم، كلمة المرور، والمنفذ `3307`).
3.  **تشغيل المشروع:**
    *   تأكد من أن خادمك المحلي (مثل XAMPP) يعمل.
    *   قم بتوجيه المتصفح إلى مجلد `public` الخاص بالمشروع (e.g., `http://localhost/your-project/public/`).
4.  **بيانات الدخول الافتراضية:**
    *   **اسم المستخدم:** `admin`
    *   **كلمة المرور:** `password`
