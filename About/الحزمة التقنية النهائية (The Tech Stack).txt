### **مسودة: الحزمة التقنية النهائية (The Tech Stack)**

---

**مقدمة:** تم اختيار هذه الحزمة التقنية بعناية لتحقيق التوازن المثالي بين القوة، البساطة، سرعة التطوير، وتجربة المستخدم الغنية.

---

### **1. الواجهة الخلفية (Back-end)**

*   **إطار العمل (Framework):** **CodeIgniter 4**
    *   **الدور:** هو العمود الفقري والعقل المدبر للنظام. سيكون مسؤولاً عن كل شيء: توجيه الطلبات (Routing)، معالجة منطق الأعمال (Business Logic)، التفاعل مع قاعدة البيانات، وإدارة جلسات المستخدمين والأمان.
    *   **لماذا؟** يوفر بيئة عمل منظمة (MVC)، أداءً عاليًا، وسهولة في النشر، مع الحفاظ على البساطة والوضوح في كتابة الكود.

---

### **2. الواجهة الأمامية (Front-end)**

*   **نظام التصميم (Design System):** **Tabler.io (آخر إصدار مستقر)**
    *   **الدور:** هو المصدر الوحيد للهوية البصرية للنظام. سيوفر كل المكونات الأساسية للواجهة من أزرار ونماذج وجداول وبطاقات وتنبيهات، مما يضمن تجربة مستخدم متسقة واحترافية.
    *   **الاستخدام:** سيتم الاعتماد عليه بشكل كامل، مع تجنب كتابة أكواد CSS مخصصة قدر الإمكان.

*   **مكتبات JavaScript الرئيسية:**
    *   **1. jQuery:**
        *   **الدور:** الأداة الرئيسية للتفاعل مع عناصر الصفحة (DOM)، وتنفيذ طلبات **AJAX** للخادم، وكنقطة انطلاق للمكتبات المساعدة الأخرى التي تعتمد عليها.
        *   **الاستخدام:** مثالي لإرسال النماذج، تحديث أجزاء من الصفحة بعد استجابة الخادم، وتشغيل المكتبات الأخرى.
    *   **2. Alpine.js:**
        *   **الدور:** لإضافة التفاعلية الديناميكية للمكونات الصغيرة داخل الواجهة **بدون الحاجة لكتابة كود JavaScript مخصص ومفصول**.
        *   **الاستخدام:** مثالي لإدارة الحالات البسيطة مثل (إظهار/إخفاء قائمة منسدلة، تفعيل/تعطيل زر بناءً على حالة حقل إدخال، عمل تبويبات (Tabs) بسيطة). إنه يكمل jQuery ولا يتعارض معه.

---

### **3. صندوق الأدوات (The Toolkit) - المكتبات الإضافية المعتمدة**

سيتم تحميل هذه المكتبات فقط في الصفحات التي تحتاج إليها لضمان بقاء النظام خفيفًا.

| الفئة | المكتبة المعتمدة | الاستخدام الأساسي |
| :--- | :--- | :--- |
| **التنبيهات والإشعارات** | **SweetAlert2 & Toastify** | الأولى للتأكيدات التفاعلية (مثل الحذف)، والثانية للإشعارات السريعة (مثل "تم الحفظ"). |
| **تحسين النماذج** | **Select2** | لتحويل القوائم المنسدلة إلى قوائم قابلة للبحث الذكي. |
| | **Litepicker** | لاختيار التواريخ والنطاقات الزمنية بواجهة احترافية. |
| | **IMask** | لفرض تنسيقات محددة على حقول الإدخال (أرقام، مبالغ، تواريخ). |
| | **Dropzone** | لرفع الملفات والمستندات بأسلوب السحب والإفلات. |
| | **Autosize** | لجعل حقول النصوص الطويلة (textarea) تتمدد تلقائيًا. |
| **عرض البيانات المتقدم** | **Handsontable** | لبناء واجهات شبيهة بـ Excel للإضافة والتعديل الجماعي للبيانات. |
| **التقارير والرسوم البيانية** | **ApexCharts** | لإنشاء كل الرسوم البيانية التفاعلية (مدمجة ومدعومة رسميًا من Tabler). |
| **تحسينات الواجهة** | **CountUp.js** | لإضافة تأثير العداد الرقمي المتحرك في بطاقات الإحصائيات. |
| | **Clipboard.js** | لإضافة وظيفة "نسخ إلى الحافظة" بسهولة. |

---

**ملاحظة هامة:** سيتم استدعاء هذه المكتبات عبر روابط **CDN (Content Delivery Network)** في مرحلة التطوير الأولية لسهولة الإعداد. قبل إطلاق المنتج النهائي، سيتم تقييم نقلها إلى ملفات محلية ضمن مجلد `public/assets` لتحسين الأداء وتقليل الاعتماد على أطراف خارجية.
